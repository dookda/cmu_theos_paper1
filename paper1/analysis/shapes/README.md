# รูปทรงของการแบ่งข้อมูลเชิงพื้นที่ (paper1)

สร้างจาก `paper1/scripts/export_split_shapes.py` และ `make_qgis_project.py`
เรขาคณิตชุดเดียวกับที่รูปที่ 1–2 ของบทความใช้ ตัวเลขทุกตัวมาจาก
`analysis/results/spatial_splits.json`

## ไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `spatial_splits.qgz`/`.qgs` | โปรเจกต์ QGIS พร้อมสไตล์ เปิดแล้วได้เลย |
| `spatial_splits.gpkg` | ข้อมูลทั้งสามชั้น **EPSG:32647** (UTM 47N) — ใช้ตัวนี้เป็นหลัก |
| `blocks.geojson` · `tiles.geojson` · `scenes.geojson` | ชั้นเดียวกันใน **EPSG:4326** ตามสเปก GeoJSON |

## ชั้นข้อมูล

**`blocks`** — 78 บล็อก ขนาด 1500 ม.
`block_id` · `split` (train/val/test/external) · `pool` (internal/external) · `n_tiles`

**`tiles`** — 2,641 ไทล์ที่ถูกใช้
`tile` · `split` (ว่าง = ถูกตัดเป็นแนวกันชน) · `buffer_dropped` (0/1) · `dropped_from`

**`scenes`** — กรอบของสองฉาก THEOS-2 (`scene1`, `scene2`)

## ตัวเลขที่ต้องตรงกับบทความ

- บล็อกภายใน 61 (train 42 / val 9 / test 10) + ภายนอก 17 = **78**
- ไทล์ที่ใช้ 2,276 + ถูกตัดเป็นแนวกันชน **365** = 2,641
- แนวกันชนตัดจาก train 315 · val 36 · test 14

## ถ้าชั้นข้อมูลขึ้นชื่อแต่ไม่มีอะไรวาด

แปลว่าไฟล์โปรเจกต์หา GeoPackage ไม่เจอ มีสามทางที่ใช้ได้ ลองไล่ลงมา:

1. **เปิด `spatial_splits.qgz`** — ทางหลัก ถ้าเวอร์ชัน QGIS ไม่ตรงให้สร้างใหม่
   ด้วย `--qgis-version` ตามหัวข้อถัดไป
2. **ลาก `spatial_splits.gpkg` เข้า QGIS ตรง ๆ** — สไตล์ถูกฝังไว้ในไฟล์แล้ว
   (ตาราง `layer_styles`) จึงได้สีตามที่ตั้งไว้ทันทีโดยไม่ต้องพึ่งไฟล์โปรเจกต์
3. **เปิด `.geojson`** — ไฟล์ `.qml` ชื่อเดียวกันวางอยู่ข้าง ๆ QGIS จะโหลดสไตล์เอง

⚠️ สาเหตุที่พบ: ไฟล์โปรเจกต์ต้องมี `<properties><Paths><Absolute>false</Absolute></Paths>`
QGIS ถึงจะแก้ path สัมพัทธ์ `./spatial_splits.gpkg` ได้ ถ้าขาดไป ชั้นข้อมูล
จะขึ้นชื่อในสารบัญแต่โหลดไม่สำเร็จ **โดยไม่มีข้อความบอกชัดเจน**

## เวอร์ชัน QGIS

ไฟล์ประกาศตัวเองเป็น **QGIS 4.0.3** ถ้าเปิดด้วยรุ่นอื่นแล้วขึ้นคำเตือนเรื่องเวอร์ชัน
สร้างใหม่ด้วยเวอร์ชันของคุณได้เลย:

```
python paper1/scripts/make_qgis_project.py --qgis-version 3.34.0
```

⚠️ สัญลักษณ์เขียนด้วยรูปแบบ `<Option>` ซึ่งเป็นของ QGIS 3.x ขึ้นไป
รูปแบบเก่า `<prop k= v=>` เป็นของ QGIS 2 และ **QGIS 4 เลิกอ่านแล้ว** —
ถ้าใช้รูปแบบเก่า โปรเจกต์จะยังเปิดได้แต่สัญลักษณ์กลับไปเป็นค่าเริ่มต้น
คือเห็นสีสุ่มแทนสีที่ตั้งไว้ **โดยไม่มีข้อความเตือนใด ๆ**

## หมายเหตุเรื่อง CRS

⚠️ เครื่องที่สร้างไฟล์นี้มี `PROJ_DATA` ชี้ไปฐานข้อมูล PROJ รุ่นเก่าของ miniforge
ทำให้ GDAL อ่าน EPSG ไม่ออกและเขียนไฟล์ออกมา**โดยไม่มี CRS** สคริปต์จึงบังคับ
`PROJ_DATA` ไปยังฐานที่ใช้ได้ก่อน import osgeo ถ้าย้ายไปเครื่องอื่นแล้วเจอ
`ERROR 1: PROJ: proj_create_from_database` ให้แก้ที่ตัวแปรนี้

GeoPackage เก็บ EPSG:32647 ตรงตามข้อมูลต้นทาง ส่วน GeoJSON แปลงเป็น WGS84
เพราะสเปกกำหนดไว้ — อย่านำพิกัด UTM ไปใส่ GeoJSON โดยไม่แปลง
